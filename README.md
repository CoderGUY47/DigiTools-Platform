## ✨ Overview

**DigiTools Platform** is a single-page productivity toolkit aggregating multiple developer-oriented utilities into one cohesive dashboard. Built on **Vite 8** and **React 19** with **Tailwind CSS v4** and **DaisyUI v5**, the platform enables users to switch between tools via a clean card-grid navigation and receive instant action feedback through **react-toastify** notifications.

---

## ❌ The Problem & ✅ The Solution

> **Developers waste time switching between dozens of bookmarked tool websites.**

| ❌ The Problem | ✅ DigiTools' Solution |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| Constantly switching browser tabs to access different tools | **Unified dashboard** bringing all tools into one navigable interface |
| Inconsistent, mismatched UIs across tool websites | **DaisyUI v5** component library delivering a coherent visual language |
| No notification when tool actions complete | **react-toastify** inline feedback on every tool action |
| Cluttered tool pages that overwhelm with options | Clean **card-grid layout** with clear tool categorization |

## 🚀 Key Features

- **🧰 Multi-Tool Hub** — Aggregated tool cards navigable from a central home dashboard.
- **🎨 DaisyUI Themed UI** — Consistent, polished component styles with Tailwind v4 integration.
- **🔔 Toast Notifications** — react-toastify alerts for every tool action confirmation.
- **📱 Responsive Layout** — Mobile-first card grids that stack cleanly on small screens.

## 🛠️ Installation & Setup

1. **Clone & Install**

   ```bash
   git clone https://github.com/CoderGUY47/DigiTools-Platform.git
   cd DigiTools-Platform
   npm install
   ```

2. **Run Locally**

   ```bash
   npm run dev
   ```
